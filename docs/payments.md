# Pembayaran Honor
Pembayaran honor Asisten Dosen FASILKOM UI dilaksanakan berdasarkan [Pengisian Log](logging.md). Pengajuan log **yang diterima** membutuhkan waktu kira-kira 1 bulan sejak pelaporan via log. Umumnya, ini berarti pencairan honor log akan dilakukan di H+2 Bulan sejak pekerjaan yang dilaporkan via [SIASISTEN](https://siasisten.cs.ui.ac.id).

Status `DIPROSES` di SIASISTEN menandakan bahwa log anda sudah mulai diproses oleh Keuangan FASILKOM UI, untuk diteruskan ke pihak Keuangan Universitas Indonesia, dan tidak menandakan bahwa honor akan segera ditransfer. Ini merupakan limitasi sistem keuangan Universitas Indonesia.

Pembayaran ke rekening non-BNI mungkin akan lebih lama daripada pembayaran ke rekening BNI, dan dikenakan biaya pemrosesan LLG sebesar Rp. 2.900,-

## Tarif Honor Asisten FASILKOM UI

Honor dihitung per jam, berdasarkan status pendidikan Anda saat menjadi asisten.

| Status | Tarif per jam |
|---|---|
| Masih menempuh program Sarjana (S1) | Rp 27.500 |
| Selain itu | Rp 32.500 |

Tarif ini sama untuk seluruh jenis pekerjaan — mengajar, mengoreksi, maupun
[mengawas](proctoring.md). Tidak ada perbedaan tarif antara Asisten Dosen dan Pengawas
Tambahan.

!!! success "Honor tidak dipotong pajak"

    Tidak ada pemotongan pajak atas honor asisten. Anda menerima penuh sebesar jam yang
    disetujui dikalikan tarif di atas, dikurangi biaya LLG bila rekening Anda bukan BNI.

    NPWP tetap **wajib** — bukan untuk pemotongan pajak, melainkan sebagai syarat administratif
    agar honor dapat dibayarkan sama sekali. Lihat [Pendaftaran Asisten](registration.md#memiliki-npwp).
